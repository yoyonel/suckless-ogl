# CONSTITUTION SUPRÊME DE SUCKLESS-OGL (V2)

## DOMAINE I : PARADIGME C11, MÉMOIRE ET ABSTRACTION (PAL)
* [LOCAL:pal][ANCRÉ][ARCHI-REVIEW] L'abstraction PAL isole de façon étanche les appels système (timers, threads, fichiers, IDs). Interdiction d'inclure des en-têtes système natifs (`<windows.h>`, `dirent.h`, `<sys/...>`) ou d'exposer leurs structures hors de la PAL (exceptions diagnostiques exclusives : `log.c`, `tracy_manager`, `perf_mode`, `gpu_usage`).
* [LOCAL:pal][ANCRÉ][COMPILATEUR] Le scan de répertoire utilise `platform_dir_list` avec callback `PlatformDirCallback`. L'allocation/libération alignée utilise `platform_aligned_alloc`/`platform_aligned_free`. Timing haute résolution via `platform_get_time_ns()` (retour `uint64_t`) et sommeil via `platform_sleep_ms()`.
* [LOCAL:async_loader/light_probes][MVP/TRANSITION][GREP] La gestion des threads dans `async_loader` et `light_probes` is en cours de migration depuis `<pthread.h>` direct vers l'abstraction PAL native.
* [GLOBAL][ANCRÉ][ARCHI-REVIEW] Point de sortie unique labeled `cleanup` via `goto cleanup` pour toute fonction acquérant plusieurs ressources. Initialiser tous les pointeurs à `NULL` lors de la déclaration pour sécuriser `free(NULL)`. Interdiction de multiplier les labels de nettoyage dans une même fonction ou de libérer en cascade.
* [LOCAL:cleanup][ANCRÉ][COMPILATEUR] Libération automatique RAII via `__attribute__((cleanup))` (macros `HYBRID_FUNC_TIMER`, `GPU_STAGE_PROFILER`). Déclarer les variables RAII en LIFO. Placer `RAII_SATISFY_FILE` et `RAII_SATISFY_FREE` sur les chemins précoces pour parer aux faux positifs Clang-Tidy (interdiction des suppressions globales `// NOLINT`).
* [GLOBAL][ANCRÉ][COMPILATEUR] Allouer `App` sur le tas via `platform_aligned_alloc` avec alignement `SIMD_ALIGNMENT` et initialiser via `*app = (App){0}`. `SphereInstance` mesure exactement 128 octets, alignée sur 64 octets (layout : `mat4 model` 64B, `vec3 albedo` 12B, `float metallic` 4B, `float roughness` 4B, `float ao` 4B, `float padding` 4B, `vec3 prev_center` 12B, `float padding2` 20B).
* [LOCAL:simd][ANCRÉ][COMPILATEUR] Bannir `calloc`/`malloc` au profit de `platform_aligned_alloc`/`posix_memalign` (alignement 64B) pour les structures à calcul vectoriel. Offloader la conversion F32 en F16 au CPU via intrinsèques AVX2/F16C (`_mm256_cvtps_ph`) avec buffer de travail temporaire `Width * Height * 8` octets.
* [GLOBAL][ANCRÉ][ARCHI-REVIEW] Les structures chaudes co-accédées doivent résider dans la même ligne de cache (64B) ou dans une proximité de 1-2 lignes. Pointeur opaque sur le tas toléré si indirection < 900 ns/frame, candidats : taille > 1 Ko, accès CPU < 200/frame. Interdiction d'opacifier des structures < 64B ou des variables critiques de la boucle de dessin.
* [LOCAL:scene][MVP/TRANSITION][ARCHI-REVIEW] Allouer `SceneVisuals` (incluant `TrailRenderer` de 128 Ko) sur le tas via pointeur opaque `visuals*` pour regrouper les champs chauds de `Scene` (taille de `Scene` ~900B, max 14 lignes de cache). Interdiction de stocker en ligne des volumes de données froides > 1 Ko dans les structures hôtes chaudes.
* [GLOBAL][ANCRÉ][COMPILATEUR] Chaque structure de données d'un module doit disposer de ses fonctions d'initialisation et de destruction explicites (`init`/`destroy`). Interdiction de déclarer des structures clés (`App`, `Camera`, `AsyncRequest`, `Shader`, `NBodySim`, `SphereInstance`) anonymement afin de ne pas bloquer les déclarations anticipées (`typedef struct X X;`). Interdiction d'inclure un en-tête complet dans un fichier `.h` si le type est manipulé uniquement par pointeur ou référence.

## DOMAINE II : MACHINE D'ÉTAT OPENGL, RÉSILIENCE ET BACKEND GRAPHIQUE
* [GLOBAL][ANCRÉ][COMPILATEUR] Exécution sous OpenGL 4.4 Core Profile. Flags de contexte GLFW obligatoires : contexte de débogage (`GL_OPENGL_DEBUG_CONTEXT`), compatibilité ascendante Apple (`GLFW_OPENGL_FORWARD_COMPAT`), MSAA désactivé (`DEFAULT_SAMPLES = 1`), et `GLFW_AUTO_ICONIFY` à `GLFW_FALSE` (évite les pertes de focus sous Wine).
* [LOCAL:app][ANCRÉ][ARCHI-REVIEW] Main() exécute le bootstrap dans l'ordre strict : 1. `tracy_manager_init_global()`, 2. `cli_handle_args()`, 3. Allocation de `App` alignée, 4. `app_init()`, 5. `app_run()`, 6. `app_cleanup()`, 7. Libération de `App`.
* [LOCAL:app][ANCRÉ][ARCHI-REVIEW] Cycle de vie via descripteurs (`SubsystemDescriptor` avec `init`/`cleanup`) dans la table `APP_SUBSYSTEM_TABLE` terminée par `{0}`. Premier module : `APP_WINDOW_DESCRIPTOR` (crée le contexte). Nettoyage dans l'ordre inverse (contexte valide, fenêtre détruite en dernier). Rollback d'échec d'index N de N-1 à 0. Procédure d'ajout en 4 étapes avec test unitaire. Tracé commenté statique : `/* Called via APP_SUBSYSTEM_TABLE in app.c (subsystem descriptor pattern) */`. Seuls les échecs de Phase 3 postérieurs à l'initialisation des descripteurs effectuent un saut vers `goto cleanup_full`.
* [LOCAL:window][ANCRÉ][ARCHI-REVIEW] Callback de débogage OpenGL synchrone (`GL_DEBUG_OUTPUT_SYNCHRONOUS`) avec déduplication par table de hachage. Désactiver la synchronisation verticale (`glfwSwapInterval(0)`). Redimensionnement différé : le callback GLFW lève `resize_pending` (membres `pending_width`/`height` de `App->win`), et les FBOs sont recréés au début de la frame suivante. Interdiction d'accéder au contexte OpenGL ou de réallouer des buffers dans les callbacks.
* [LOCAL:pal][ANCRÉ][GREP] La reprise de focus souris sous Wine lors du passage plein écran requiert le basculement de mode de `GLFW_CURSOR_NORMAL` vers `GLFW_CURSOR_DISABLED` suivi de `glfwSetCursorPos()`.
* [LOCAL:renderer][ANCRÉ][ARCHI-REVIEW] Billboard Ray-Tracing analytique par défaut pour les sphères : projeter un quad par instance (`glDrawArraysInstanced` sur 4 sommets), intersection rayon-sphère dans le fragment shader, écriture de normale et de `gl_FragDepth`. Rendu d'icosphères maillées instanciées (`glDrawElementsInstanced`, subdivision [0,6]) comme unique solution de secours si `billboard_mode == 0`. Effectuer un tri back-to-front sur CPU/GPU avant le rendu des sphères transparentes pour le mélange alpha.
* [LOCAL:postprocess][ANCRÉ][RUNTIME/PROFILER] FBO principal MRT : `GL_COLOR_ATTACHMENT0` (`GL_RGBA16F`), `GL_COLOR_ATTACHMENT1` (vélocité `GL_RG16F`), `GL_DEPTH_STENCIL_ATTACHMENT` (`GL_DEPTH32F_STENCIL8`), et Stencil View (`GL_R8UI`). Texture Units 0-8 réservées dans l'ordre (Couleur, Bloom, Profondeur, Exposition, Vélocité, Neighbor Max, DoF, Stencil, LUT 3D).
* [LOCAL:postprocess][ANCRÉ][COMPILATEUR] Spécifications PP : Résolution FBO 1920x1080. Bloom à 6 mipmaps (`GL_RGBA16F`). 3D LUT géométrique 32x32x32 (`GL_RGB16F`/`GL_RGBA16F`). Cache LRU de variantes max 32. Bitmask d'activation des effets (`active_effects` de type `uint32_t`) évalué par opération bit à bit dans le shader (`activeEffects & (1u << N)`). Préfixer les identifiants d'énumérations d'unités de texture du post-traitement par `POSTPROCESS_TEX_UNIT_`.
* [LOCAL:ubo][ANCRÉ][COMPILATEUR] Correspondance binaire stricte std140 : alignement de `PostProcessUBO_Layout` (C) et `PostProcessBlock_Layout` (GLSL). Scalaires sur 4 octets, vec2 sur 8 octets, vec3/vec4/mat4/blocs sur 16 octets. Déclarer les paddings sous forme de scalaires individuels (ex: `float _pad1_0;`). Interdiction d'utiliser des tableaux de padding.
* [LOCAL:ubo][ANCRÉ][RUNTIME/PROFILER] Mise à jour UBO : transfert unique par frame de l'intégralité du bloc via `glBufferSubData` avec copie stack C de l'UBO. Interdiction d'envoyer via des appels `glUniform*` ou `glUseProgram` individuels par frame.
* [LOCAL:vertex_attrib][ANCRÉ][GREP] Découpler le format des sommets via `glVertexAttribFormat`/`Binding`/`glBindVertexBuffer` (liaisons : 0-1 géométrie, 2 instances). Interdiction d'utiliser `glVertexAttribPointer`. Interdiction de convertir des entiers en `void*` pour les offsets.
* [LOCAL:opengl][ANCRÉ][CTEST/ASAN] Appeler `glObjectLabel` uniquement après la liaison (`glBind`) effective de l'objet. Lock des textures globales par défaut (`dummy_black_tex`) pour empêcher leur destruction locale. Uniformiser les formats de sommets et forcer `glVertexAttribDivisor(index, 0)` sur les slots 8-15 non-instanciés pour éviter les recompilations à la volée. Lier des textures dummy 1x1 (noire/blanche) sur les unités actives non utilisées. Réassocier toutes les unités de texture utilisées (0 à 6) à une texture par défaut valide à la fin de `postprocess_resize`. Utiliser des SSBO persistants configurés avec `GL_CLIENT_STORAGE_BIT` à l'exclusion de lectures synchrones via PBO pour les calculs de luminance.
* [LOCAL:dependencies][ANCRÉ][ARCHI-REVIEW] Le module de rendu bas niveau (renderer) doit exécuter le rendu de l'interface utilisateur via un type opaque `RenderUIFn` (`typedef void (*RenderUIFn)(void* user_data)`) et la fonction trampoline `app_render_ui_trampoline`.
* [LOCAL:input][ANCRÉ][GREP] Raccourcis clavier de contrôle : C (caméra), SPACE (caméra pos), W (fil de fer), Up/Down (subdivisions), PageUp/PageDown (LOD IBL), F (plein écran), ESC (fermeture). Découpler l'acquisition d'entrées physiques de la simulation de la caméra via le patron Bridge en utilisant `GamepadContext`.

## DOMAINE III : CONCURRENCE, ASYNCHRONISME ET PROGRESSIVITÉ (IBL)
* [LOCAL:async][ANCRÉ][ARCHI-REVIEW] Découpler les threads : le worker thread E/S gère le chargement disque (`stbi_loadf`), décodage et conversion SIMD F32/F16 en RAM CPU libre de contexte OpenGL ; le thread de rendu principal gère le contexte OpenGL et les allocations GPU (budget temps de boucle < 16.6 ms, tâches bloquantes CPU/E/S < 1-2 ms, max 5 ms pour poll de l'async loader). Interdiction d'effectuer des lectures de fichiers synchrones ou de l'I/O bloquant sur le thread de rendu principal.
* [LOCAL:async][ANCRÉ][ARCHI-REVIEW] Accès à la structure `AsyncRequest` protégé par `request_mutex`. Le worker s'endort sur `request_cond` en état `ASYNC_WAITING_FOR_PBO` (réveil par le thread principal après mappage PBO) et libère `request_mutex` lors des calculs SIMD/chargements. Les sondes GI communiquent asynchronement via `pthread_mutex_trylock` sans bloquer.
* [LOCAL:async][ANCRÉ][RUNTIME/PROFILER] Double-buffering PBO : alterner entre deux PBO persistants (`upload_pbo[2]`) à chaque frame (`frame % 2`). Mappage sans synchro via `glMapBufferRange` avec `GL_MAP_UNSYNCHRONIZED_BIT`. Interdiction de pratiquer le buffer orphaning via `glBufferData(..., NULL)` sur des tampons > 64 Mo.
* [LOCAL:async][ANCRÉ][ARCHI-REVIEW] Téléversement sur 3 frames : Frame N (mappage PBO, envoi au worker), Frame N+1 (pré-allocation VRAM du mip 0 via `glTexImage2D(..., NULL)`), Frame N+M (démappage PBO, transfert DMA via `glTexSubImage2D` et mipmaps via `glGenerateMipmap`). Interdiction d'allouer la VRAM et d'écrire par DMA dans la même frame.
* [LOCAL:async][ANCRÉ][COMPILATEUR] Transition d'état de requête : `ASYNC_IDLE` -> `ASYNC_PENDING` -> `ASYNC_LOADING` -> `ASYNC_WAITING_FOR_PBO` -> `ASYNC_CONVERTING` -> `ASYNC_READY` -> `ASYNC_IDLE`/`ASYNC_FAILED`. Membres `App` requis : `pending_prealloc_w`/`h`, `recycled_hdr_tex`, `upload_pbo` (GLuint[2]), `upload_pbo_size` (size_t[2]).
* [LOCAL:ibl][ANCRÉ][RUNTIME/PROFILER] Cycle de l'IblCoordinator : `LUMINANCE` -> `LUMINANCE_WAIT` -> `SPEC_INIT` -> `SPEC_MIPS` -> `IRRADIANCE` -> `DONE` (rebouclage sur `IDLE` après transfert). Slicing temporel GPU : Specular Mip 0 en 24 slices (~25-35 ms/frame), Mip 1 en 8 slices (~15-25 ms/frame), Mip 2 en 1 slice, Mips 3-10 groupés (~20 ms total), Irradiance en 12 slices (~5 ms/slice), Luminance en 2 dispatches. Enveloppe stricte : 10-15 ms/frame par tranche (calcul total 850-950 ms).
* [LOCAL:ibl][ANCRÉ][ARCHI-REVIEW] Désactiver le slicing IBL sur GPU logiciel (llvmpipe) pour faire 1 dispatch global par carte (luminance conserve ses 2 dispatches). Interdiction de lever le fondu noir de transition (`transition_alpha = 1.0`) et d'afficher la scène 3D avant l'état `IBL_STATE_DONE` (textures de secours 1x1 liées en attendant).
* [LOCAL:ibl][ANCRÉ][GREP] Shaders compute IBL (taille 32x32) : injecter les limites de tranches `u_max_y_slice` (ou `u_max_y`) et `u_offset_y`. Filtre de garde obligatoire dans le shader : `pixel_pos.y >= u_max_y_slice`. Unique barrière `glMemoryBarrier(GL_SHADER_IMAGE_ACCESS_BARRIER_BIT)` appelée à l'état final `DONE` (interdiction des barrières par tranche).
* [LOCAL:ibl][ANCRÉ][GREP] Résolution max de carte spéculaire IBL préfiltrée : 1024x1024 (ou 1024x512). Wrap modes : S mode `GL_REPEAT` (horizontal pour cartes équirectangulaires, interdiction de `GL_CLAMP_TO_EDGE`), T mode `GL_CLAMP_TO_EDGE`. Irradiance échantillonnée à MIP 0.0 fixe via `textureLod()` pour parer aux jointures.
* [LOCAL:ibl][ANCRÉ][ARCHI-REVIEW] Transfert de propriété strict des ressources via `ibl_coordinator_get_results` et mise à NULL immédiate des handles internes pour éviter toute double-libération.
* [LOCAL:sync][ANCRÉ][RUNTIME/PROFILER] Readbacks GPU asynchrones (luminance, histogrammes) : lecture dans un PBO double-bufré suivi de `glFenceSync`. Interrogation asynchrone sans blocage via `glClientWaitSync` (timeout 0 ns) ; reporter l'intégration CPU à la frame suivante si non signalé.
* [LOCAL:ibl][MVP/TRANSITION][ARCHI-REVIEW] Réduire les échantillons par mipmap : implémenter un échantillonnage adaptatif en transmettant `u_sample_count` aux compute shaders pour décroître le nombre d'échantillons sur les mipmaps de haute rugosité.
* [LOCAL:ibl][MVP/TRANSITION][GREP] Nomenclature de l'uniforme d'échantillonnage : utiliser la variable uniforme `u_sample_count` (int) pour la commande dynamique d'échantillons spéculaires.
* [LOCAL:ibl][ANTI-PATTERN][RUNTIME/PROFILER] Interdiction d'effectuer des allocations ou libérations de ressources GPU critiques pendant la phase de mise à jour à chaque frame.
