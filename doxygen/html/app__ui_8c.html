◆ gp_axis_active()

static bool gp_axis_active ( const float *  axes,
int  axis_id,
const GamepadState *  pad 
)
static

Test whether a raw GLFW axis value exceeds its activation threshold.

Triggers (axes 4-5) rest at -1.0 and range to +1.0, so they are normalised to [0,1] before comparing against the trigger threshold. Stick axes (0-3) are centred at 0.0 and compared via fabsf against the deadzone.
