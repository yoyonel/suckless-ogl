Detailed Description

N-body gravitational simulation (Velocity Verlet + Plummer softening).

Manages a set of gravitational bodies with position, velocity, and mass. Uses a symplectic Velocity Verlet integrator with per-pair Plummer softening to guarantee long-term energy conservation without ad-hoc damping. Produces SphereInstance data for the instanced renderer.

See also
docs/nbody_physics.md for the full physics reference.
