Detailed Description

Parameter structs and defaults for uber-shader post-processing effects.

Contains configuration structs for effects that run inside the combined uber-shader pass (Vignette, Grain, Exposure, ChromAbbr, WhiteBalance, ColorGrading, Tonemap, FXAA, Banding, Fog). Effects with their own multi-pass pipeline (Bloom, DoF, AutoExposure, MotionBlur, LUT3D) define their params in their respective fx_*.h headers.
