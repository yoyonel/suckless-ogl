Detailed Description

Reads GPU utilization % via Linux DRM fdinfo (same method as MangoHud).

Scans /proc/self/fdinfo/ for DRM render node file descriptors, reads cumulative engine time (drm-engine-render for i915, drm-engine-gfx for amdgpu, etc.), and computes utilization as delta_gpu_time / delta_wall_time.

Supported drivers: i915, xe, amdgpu, nouveau.
